# Practical JavaScript Web Seminar
## Three beginner-friendly projects

This seminar teaches asynchronous JavaScript, DOM events, and resilient HTTP requests through small, hands-on projects.

### Requirements
- A modern browser (Chrome, Firefox, Edge, etc.)
- Visual Studio Code or another text editor
- Optional: the Live Server extension for VS Code
- Internet access for the API lessons

No Node.js, build tools, or frameworks are required.

### Lessons
1. `01-multi-source-dashboard` — parallel fetch requests, `Promise.all`, HTTP errors, UI states, rendering.
2. `02-interactive-task-list` — model/render flow, safe DOM creation, event delegation, target/currentTarget, cleanup.
3. `03-resilient-fetch` — timeouts, aborting, retries, exponential backoff, error classification, stale requests.
